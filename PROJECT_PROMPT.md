# Prompt для создания сайта

Используй `$design-direction` как отдельный дизайн-слой. Не смешивай дизайн-правила со структурой, деплоем и бизнес-логикой.

Собери одностраничный сайт маркетингового агентства “ПроДвижение”.

## Контекст

- Название: ПроДвижение
- Домен: marketing-for-business.ru
- Язык: русский
- География: Россия
- Целевая аудитория: малый бизнес
- Главная услуга: маркетинг
- Направления: SEO, контекстная реклама в Директе, таргетированная реклама ВК, Авито, email-маркетинг
- Обещание: сначала делаем маркетинговый анализ, затем выбираем инструменты и специалистов, которые реально подходят бизнесу клиента
- Стиль: технологично-креативный, без типичного AI-градиента и шаблонных карточек

## Структура первой версии

- Главная секция с сильным оффером
- Услуги
- Кейсы как подготовленные места без выдуманных результатов
- Процесс работы
- Пакеты/цены без конкретных сумм до утверждения
- Отзывы как подготовленные места
- FAQ
- Форма заявки
- Политика конфиденциальности

## Технические требования

- Astro
- Netlify
- Netlify Forms
- Адаптивность
- Базовое SEO
- Подготовка к аналитике через переменные окружения
- Без реальных фото, реквизитов и выдуманных кейсов
